`scatter3d` and 3D hover (M6 wave 1, plan E14.2, E14.1d). The new `scatter3d` trace draws markers, lines and text at `x`, `y`, `z` in a 3D scene with Plotly's attributes and defaults (`mode` `'lines+markers'`, `marker.size` 8): Plotly's eight 3D symbols, marker and line colors direct or through colorscales (lines interpolate per-point colors along each segment), bubble sizes, screen-space `line.width` and `line.dash`, `connectgaps`, camera-facing `text` / `texttemplate` / `textposition` / `textfont`, `error_x` / `error_y` / `error_z` (`copy_zstyle`; the scene's autorange includes them), `projection.{x, y, z}` (the markers' shadows on the far walls), `surfaceaxis` / `surfacecolor` (a Delaunay surface through the points), `x` / `y` / `zhoverformat`, legend glyphs and colorbars; `marker.render: 'sphere'` (a Holochart extension) draws lit spheres. Each part is one draw call whatever the point count; 1M points orbit interactively. 3D hover picks markers and lines on the GPU (occlusion-aware, one pick per pointer position for the whole scene): Plotly's `x: …<br>y: …<br>z: …` labels at the projected point with values formatted per scene axis, `hovertemplate` with `%{z}`, `hover` / `click` events carrying `x`, `y`, `z` (a click in a scene emits the hovered point), spikes to the walls (`showspikes`, `spikesides`, `spikecolor`, `spikethickness`), labels that hide while the camera moves and come back when it rests; `scene.annotations[]` anchor 2D-styled annotations (arrows, boxes, rich text, `captureevents`) at 3D points, following the camera. For 3D trace authors: `registerScenePickable`, `invalidateScenePicks`, `scenePicks` and `sceneHoverPoint` (see the scene module's contract). The runtime gains `chart.refreshHover()` (hover again at the pointer, for asynchronous hover sources); core now holds the annotation item attributes (`annotationItemAttributes`) and render the annotation arrow and rotated-box geometry (`arrowGeometry`, `ARROWHEADS`, `rotatedBoxCorners`, …), which the annotations component re-exports unchanged. The default look gives `scatter3d` 5 px markers with background-colored rims.
