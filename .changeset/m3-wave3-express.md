New `@mk7s/holochart-express` package: Plotly Express-style charts from tabular data (`import hx from '@mk7s/holochart-express'`). Data can be row objects, an object of columns, an Apache Arrow table (duck-typed, no dependency) or CSV text parsed with `fromCSV` (RFC 4180, numbers typed like pandas); column types are inferred (numeric, date, categorical), and column options take a name or an array. `scatter`, `line`, `area`, `bar`, `timeline`, `pie`, `histogram`, `box`, `violin`, `strip`, `ecdf`, `densityHeatmap`, `densityContour`, `scatterMatrix`, `parallelCoordinates` and `parallelCategories` follow px's arguments (camelCase) and figure structure: one trace per `color` / `symbol` / `lineDash` / `pattern` group with px's names, legend groups and hover templates, `labels`, `categoryOrders`, colors from the template's colorway or `colorDiscreteSequence` / `colorDiscreteMap`, a numeric `color` on `layout.coloraxis` with a colorbar, `hoverName` / `hoverData` / `customData`, `logX` / `logY`, `rangeX` / `rangeY`; facet grids (`facetRow`, `facetCol`, `facetColWrap`, spacing) with axes linked by `matches` and facet labels; `animationFrame` / `animationGroup` frames with `ids`, px's play / pause buttons and slider, and axis ranges fixed across frames; ECDFs (`ecdfnorm`, `ecdfmode`); marginals (`marginalX` / `marginalY`: histogram, box, violin, rug); and `ff.distplot` (plotly.py's `create_distplot`: probability-density histograms, a Gaussian KDE with Scott's rule or a normal fit, and a rug). Each function returns a plain figure, or renders it when given an element first. Core exports `FACET_LABEL_NAME`; a legend above the plot area (the default look's) now sits above the top row's subplot titles and facet labels instead of over them.
