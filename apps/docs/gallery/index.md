# Gallery

The gallery will show a thumbnail of every example, in light and dark themes. Thumbnails are
generated from the same examples that the docs embed and the visual tests check.

Planned features:

- Filters by category, tag, trace type, and 3D-native options
- Links from each thumbnail to its docs page and to the playground

Until then, see the [chart types](/charts/) overview.
