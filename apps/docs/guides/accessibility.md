# Accessibility guide

This guide will explain what Holochart does for accessibility by default and what you should add.

Planned topics:

- The DOM mirror: how a canvas chart is described to assistive technology
- Auto-generated chart summaries and writing your own descriptions
- Data table fallback
- Keyboard navigation and focus
- Color-blind-safe palettes, high-contrast themes, and patterns
- Reduced motion
- Locales for numbers and dates

The baseline (DOM mirror) lands in M2; keyboard navigation, summaries, and locales follow in later
milestones.
