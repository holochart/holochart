# Server-side rendering

This guide will explain how to use Holochart with server-rendered frameworks, and how to render
chart images without a browser window.

Planned topics:

- Loading Holochart only on the client in Next.js, Nuxt, SvelteKit, and similar frameworks
- Rendering a placeholder with the right size to avoid layout shift
- Headless image generation on a server
- Building figures on the server and sending them as JSON
