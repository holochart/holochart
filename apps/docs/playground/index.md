# Playground

The playground will be a live editor for Holochart figures, running entirely in the browser.

Planned features:

- An editor with autocomplete from the generated TypeScript types
- JSON figure, TypeScript, and Express modes
- Inline validation errors from the schema
- Shareable links (the figure is stored in the URL, no server needed)
- Export to CodeSandbox and StackBlitz
- "Open in Playground" from every docs example
