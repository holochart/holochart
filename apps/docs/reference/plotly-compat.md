# Plotly compatibility

This page will be a table of Plotly.js trace types and attributes and their status in Holochart:
supported, supported with differences, or not supported. It will be generated from the Plotly
importer's coverage data, and it will include the share of the plotly.js test mock corpus that
the importer renders without errors.

Until then, see the [chart types](/charts/) overview for which trace types are planned and when,
and [Coming from Plotly](/getting-started/from-plotly).
