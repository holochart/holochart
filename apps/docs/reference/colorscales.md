# Colorscales & palettes

This page will be generated from Holochart's colorscale and palette registries, so it always
lists exactly what is built in. Click a swatch to copy its name.

Planned contents:

- Qualitative palettes (Plotly, D3, G10, T10, Dark24, Set1 to Set3, Safe, ...)
- Sequential colorscales (Viridis, Cividis, Inferno, Magma, Plasma, Turbo, and the cmocean and
  carto scales)
- Diverging and cyclical colorscales
- Reversed `_r` variants

See also [Colors, colorscales & colorbars](/fundamentals/colors-colorscales).
